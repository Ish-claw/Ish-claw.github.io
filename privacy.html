Area 51 Trading Desk

Privacy Policy

Effective date: 25 November 2026

1. Application Purpose

Area 51 Trading Desk is a private personal financial research and data management application intended for its authorized owner.

2. Google User Data

The application uses Google Drive authorization to access, read, create, update and synchronize files for its authorized owner.

3. Data Usage

Google Drive data is used for authorized file management, synchronization, storage and personal financial research.

4. Data Sharing

The application does not sell Google user data or use it for advertising. Access is intended solely for the authorized owner and services explicitly authorized by that owner.

5. Data Security

Access is controlled through Google OAuth authorization. Credentials and private files are not published on this website.

6. Data Retention and Deletion

The owner controls the retention and deletion of files and synchronized copies. Google Drive access may be revoked at any time through Google Account security settings.

7. Google API Compliance

The application is intended to comply with the Google API Services User Data Policy, including its Limited Use requirements.

8. Contact

For privacy inquiries, contact the application owner through the support email associated with the Google OAuth application.
